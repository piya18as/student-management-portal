# Student Management Portal

A simple web-based Student Management Portal designed to manage and display student information through an easy-to-use interface.

## Features

* Add and manage student information
* Display student records in an organized format
* Interactive and responsive user interface
* Simple navigation and user-friendly design
* Basic student data management using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
student-management-portal/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

> The project structure may vary depending on the current implementation.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/piya18as/student-management-portal.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional installation is required.

## Project Purpose

This project was developed to practice frontend web development, JavaScript-based interaction, and basic student data management.
